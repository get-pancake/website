## What "OpenClaw hosting" means

OpenClaw is a free, open-source personal AI agent. You talk to it through the chat apps you already use (WhatsApp, Telegram, Slack, Discord, Signal, iMessage and more), and it acts for you: it runs commands, browses the web, manages files and runs scheduled jobs. It took the name OpenClaw on January 30, 2026, after a few days as Moltbot, and many older guides still call it Clawdbot. The OpenClaw Foundation, a US nonprofit, stewards the project. The GitHub repository had more than 390,000 stars on September 24, 2026.

The project sells nothing. Its site says there is no subscription and no hosted tier. So every "OpenClaw hosting" offer is a third party running the open-source code on a server for you.

Why a server at all? OpenClaw only works while the machine running it is on. On a laptop, your agent stops when the lid closes. A server keeps it reachable around the clock, which matters for scheduled jobs and for messages that arrive at 3 a.m.

You have three routes:

| Route | Who runs the server | Typical cost (Sept 2026) | Best for |
|---|---|---|---|
| Managed hosting | The provider: install, updates, backups, uptime | $0 to $29.99/month entry plans, plus model usage unless credits are bundled | Non-technical users who want an agent in Telegram today |
| One-click VPS | You, starting from a preinstalled image | From $6.49/month (promo) to $24/month for the server | Developers who want root access without a manual install |
| Self-hosting | You, from scratch | Nothing extra on your own hardware, or the price of a rented VPS | Engineers who want full control |

### Agent 37: the cheapest way to start

Agent 37 runs OpenClaw, Hermes Agent and other agent frameworks in isolated sandboxes. The free tier gives you one agent with 1 vCPU and 4 GB of RAM. It sleeps after 15 minutes idle and wakes when you message it, and it needs no card.

Basic costs $3.99/month for an always-on instance. Pro, at $29.99/month, adds a built-in Chromium browser for web tasks. You bring your own API keys on every tier. Developers can also create instances through its Cloud API, billed per minute, from $4.76/month for an always-on 2 vCPU machine.

**Pick it if** you want OpenClaw on a server this afternoon without paying anything.

### Hostinger: AI credits at a promo price

Hostinger's Managed OpenClaw starts at $5.99/month on a promotional term paid upfront, and renews at $11.99/month. It ships with AI credits already loaded, Telegram or WhatsApp pairing, web search and a separate mailbox for the agent. You don't need an account with a model provider to start. Hostinger also sells a VPS with OpenClaw preinstalled, covered in the one-click section below.

**Pick it if** you want model access included and don't mind paying for the whole term upfront.

### xCloud: a dedicated server someone else patches

Each xCloud customer gets a dedicated, managed VPS. The smallest size has 4 vCPU, 6 GB of RAM and 100 GB of NVMe storage. It costs $9.99 for the first month, then $19.99/month. xCloud handles provisioning, security patches, SSL, backups and one-click restore, with 30+ server locations. Telegram works out of the box. You connect your own model key.

**Pick it if** you want the agent to have full system access (it can install its own tools) without being the person who fixes the server.

### StartClaw, DockClaw and OneClaw: credits bundled into the plan

These three package OpenClaw as a ready-to-use AI worker and fold model usage into the price through credits.

- **StartClaw** starts at $9/month for one agent with 500 credits and 20 sandbox hours a month. Pro, at $29/month, raises that to 1,500 credits and 50 hours.
- **DockClaw** Starter is $19.99/month: you bring your own API key and get an OpenClaw deployment on a shared 8 GB VM, $40 of AI credits a month and a Telegram bot. Pro, at $49.99/month, moves you to a dedicated VM.
- **OneClaw** starts at $29.99/month with 6,000 credits. It states on its site that it is independent from the OpenClaw project.

**Pick one if** you want model usage inside the plan price and can live with a monthly credit limit.

### MyClaw: a private instance with room to grow

MyClaw hosts OpenClaw and Hermes Agent on a private, encrypted instance with daily backups and automatic updates. Lite costs $19/month (2 vCPU, 4 GB of RAM), or $199 billed yearly. Pro, Max and Ultra add CPU and RAM, and their yearly plans add AI credits. MyClaw's pricing page notes that token usage is not included in the subscription.

**Pick it if** you need a larger instance or want to switch between OpenClaw and Hermes Agent later.

## Self-hosting OpenClaw: what it takes

The software is free. You pay for the machine and the model.

What you need:

- **A machine that stays on.** An old laptop, a Raspberry Pi, a home server or a VPS.
- **Node 24.16+ or 26.1+.** The official installer script sets Node up for you on macOS and Linux. Docker, Podman, Nix and Ansible installs are also documented.
- **A model.** An API key from a model provider, or a local model.

What to get right on a server:

- **Keep the Gateway private.** On a regular install it binds to loopback by default. Reach it through an SSH tunnel or Tailscale Serve. Container images expose the bind by default, so check before you publish a port.
- **Set a shared secret before you expose it.** The docs require `gateway.auth.token` or `gateway.auth.password` beyond loopback, unless an authenticated reverse proxy handles access.
- **Audit after every change.** `openclaw security audit` flags drift from the secure defaults.
- **Read third-party skills before you install them.** An agent with shell access that reads untrusted content can be steered by prompt injection.

The hidden cost is your time. OpenClaw versions are numbered by date, and new ones ship most weeks (2026.9.6 came out on September 23). Each release is yours to apply and test. For a deeper look at that trade-off, read [OpenClaw for founders: managed vs DIY](/blog/openclaw-for-founders-managed-vs-diy).

## The cost most comparisons skip: the model bill

Hosting is the small line on the invoice. The model is the big one. Kilo's own OpenClaw cost breakdown, published in April 2026, put the model bill at 95% of what users pay. An agent that reads your inbox, browses the web and runs scheduled jobs sends a lot of text to Anthropic, OpenAI or whichever model you pick. BYOK hosts pass that bill straight to you.

Two ways to keep it predictable:

- **Fixed number:** pick a host that bundles credits (Hostinger, StartClaw, DockClaw, OneClaw). Watch the limit, because heavy use runs out before the month does.
- **BYOK with guardrails:** set a monthly limit in your model provider's console and send routine tasks to a cheaper model.

## Alternatives to OpenClaw itself

Sometimes the better move is a different agent. Three open-source projects come up most often. All three were active on GitHub on September 24, 2026:

- **Hermes Agent**, by Nous Research. MIT license, about 249,000 GitHub stars. Its pitch is a learning loop: it creates skills from completed tasks and improves them as it uses them. It runs on a small VPS or serverless backends that sleep when idle, and MyClaw and Agent 37 host it.
- **NanoClaw.** MIT license, about 31,000 stars. A lighter alternative that runs agents in containers for isolation and is built on Anthropic's Agents SDK. It connects to WhatsApp, Telegram, Slack, Discord and Gmail.
- **ZeroClaw.** Apache-2.0 license, about 33,000 stars. A small, fast personal assistant runtime written in Rust, built to run on any OS.
